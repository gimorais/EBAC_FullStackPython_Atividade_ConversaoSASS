# 🎨 Refatoração CSS para SASS

---

## 📋 Descrição

Projeto de refatoração do CSS tradicional para SASS, explorando boas práticas de organização, reutilização e modularização de estilos.

Neste exercício foram aplicados:

- Conversão do CSS para sintaxe SCSS;
- Criação e uso de variáveis para cores, fontes e breakpoints;
- Modularização dos estilos em arquivos parciais com `@use`;
- Utilização de media queries com variáveis para responsividade;
- Organização clara da estrutura dos arquivos, separando configurações e componentes.
